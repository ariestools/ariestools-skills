# Aries Tools Skills

Aries Tools Skills teaches a coding agent how this organization's repositories are built and reviewed. The eight skills cover TypeScript and Git practice, the xy toolchain, the JavaScript and React SDKs, actor and host kits, repository documentation, product planning, and distributed architecture.

Install the plugin from the Aries Tools marketplace and enable ariestools-skills. There is no account, API key, or local server to configure. The plugin is markdown guidance for the agent. It does not call an external service, and it does not read credentials from your machine.

After installation, a skill loads when the task matches it: building or testing a repository, choosing a package, writing an actor, planning a product, or reviewing a distributed design. Start with the skill the task names and follow its links to the narrower reference you need.
