# Skills sync audit (complete) — xy-agent

This document records the completed audit of `skills/xy-agent/` at ariestools-skills `7e78933a8`. The skill was checked against `@ariestools/toolchain` 10.1.1 (main `812b27a91`), `@ariestools/sdk` 9.0.1 (`298fbb5bb`), the workspace repositories, and vendor documentation for Claude Code, Codex, Copilot and Gemini CLI. Every open item below was found by an auditor and then confirmed by two independent verifiers, one checking code truth and one checking the skill text. Overlapping auditors produced 131 raw findings, which merge into 42 open items; 2 findings were refuted and 5 resolved upstream. This document does not show that any fix has been applied. It is not a priority-ordered remediation plan, and no agent using the skill has tested the recommended replacement text. It supersedes the partial 2026-10-08 audit. ## Summary

The skill was written on 2026-09-01 as the specification for a future `xy agent` command. Toolchain 10.1.1 shipped that command as stable and runs `xy agent lint` inside `xy check`, so the skill is now enforced by its own catalog, and three of its own artifacts fail error-level rules: the adapter templates fail agents.adapter-thin, the AGENTS.md headings fail agents.required-sections, and the docs index example fails docs.index-current. "Recommended, not required" and "no `xy agent` command yet" are false on 10.1.1. Both are still true on the ≤10.1.0 toolchains that 45 of 49 consumers run, so every fix must be version-gated. Most of the rest is medium. Three groups make up most of it:

- The experimental `xyex plan lint` layout: the skill should warn about it, not adopt it.
- `xy work` guidance that the CLI cannot carry out.
- Places where shipped tool behaviour (archive, supersededBy, stale, decision naming) diverges from the skill. For each, the maintainers must decide whether the skill or the toolchain moves.
